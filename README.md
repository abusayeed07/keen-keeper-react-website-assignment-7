# 🌿 KeenKeeper

## 📖 Description

**KeenKeeper** is a digital relationship management tool designed to help you nurture and maintain meaningful connections with the people who matter most. Browse, track, and log interactions with your friends to build a rich timeline of your relationships.

Stop forgetting important conversations and start building stronger connections. KeenKeeper helps you stay on top of your social life by providing a centralized dashboard to manage friendships, log calls, texts, and video chats, and visualize your relationship history.

## 🛠️ Technologies Used

### Frontend
- **React 18** - UI library for building component-based interfaces
- **React Router DOM v6** - Client-side routing for navigation
- **Tailwind CSS** - Utility-first CSS framework for styling
- **Vite** - Next-generation build tool and dev server

### State Management & Data
- **React Context API** - Global state management for friends and timeline data
- **LocalStorage** - Persistent data storage for user interactions

### Icons & Notifications
- **Heroicons** - Beautiful SVG icons
- **React Toastify** - Toast notifications for user feedback
- **React Hot Toast** - Additional notification system

### Development Tools
- **ESLint** - Code linting
- **Vercel** - Hosting and deployment platform

## ✨ Key Features

### 1. 📇 Friend Management System
- Add, edit, and delete friends with detailed profiles
- View all friends in a responsive grid layout
- Search and filter through your friend list
- Each friend profile stores name, relationship type, and notes

### 2. 📊 Interaction Timeline
- Log calls, texts, and video chats with specific friends
- Filter timeline by interaction type (calls, texts, or videos)
- View chronological history of all interactions
- Delete individual entries or clear entire timeline with one click
- Persistent storage using browser's LocalStorage

### 3. 🎨 Beautiful & Responsive UI
- Modern, clean interface with Tailwind CSS
- Fully responsive design (mobile, tablet, desktop)
- Smooth hover effects and transitions
- Toast notifications for all user actions
- Dark-themed footer with social media links
- Empty states with helpful guidance
